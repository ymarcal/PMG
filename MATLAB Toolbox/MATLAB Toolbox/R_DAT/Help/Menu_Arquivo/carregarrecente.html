Menu Arquivo    

 

Carregar Arquivo Recente

 

Essa operação permite carregar rapidamente um dos arquivos de dados .mat abertos recentemente.

 

Clique no menu “Arquivo ► [arquivo recente desejado]”.

 

O R_DAT questionará se o usuário deseja confirmar o carregamento:

 

 

Ao clicar “Sim”, o R_DAT irá localizar e carregar o arquivo.

 

Nota: Se o arquivo atual não tiver sido salvo e o usuário quiser carregar outro arquivo, o R_DAT questionará se o usuário deseja salvar o arquivo atual.

 

A lista de arquivos recentes comporta quatro arquivos e é atualizada da seguinte forma:

 

  - Sempre que um arquivo é carregado ou salvo seu caminho é acrescentado à lista;

  - Arquivos são apresentados em ordem cronológica inversa (mais recente primeiro);

  - Um único arquivo só é apresentado uma vez;

  - Arquivos não encontrados no momento do carregamento são excluídos da lista;

  - Arquivos importados de outros formatos não são acrescentados à lista.
