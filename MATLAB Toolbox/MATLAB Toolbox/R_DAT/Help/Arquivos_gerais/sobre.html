Sobre o R_DAT    

 

Descrição

 

O R_DAT é um programa de manipulação, redução e análise de dados desenvolvido pela Divisão de Ensaios em Voo do Instituto de Pesquisas e Ensaios em Voo (IPEV/EEV).

 

O R_DAT 7.0 BETA (e suas atualizações até a BETA 14) foi desenvolvido em ambiente MATLAB versão 6.5 instalado em sistema operacional Windows XP. A versão 7.15 BETA foi adaptada para executar em MATLAB versão 7.8 instalado em sistema operacional Windows 7. O ambiente gráfico foi projetado para permitir uma interface amigável ao usuário, seguindo o padrão de menus, botões e listas usuais do sistema operacional Microsoft Windows, privilegiando o uso do mouse nas operações. Layout da tela principal.

 

O programa permite o carregamento de arquivos no formato MATLAB (.mat) contendo variáveis no padrão adotado pelo IPEV para dados de instrumentação de aeronaves, ou em um padrão alternativo adotado por algumas empresas.

 

Adicionalmente, o programa permite a importação de dados em outros tipos de arquivo, seguindo uma formatação específica. São suportados, além do formato .mat, arquivos de processamento DGPS (arquivos J e C), arquivos de texto (.txt, .dat, etc.), planilhas MS Excel (.xls), arquivos de dados de instrumentação autônoma e arquivos de dados de motores e sistemas das aeronaves F-5M e A-29 (.xml). Também é possível a exportação de dados para os formatos planilha Excel e texto.

 

As matrizes de dados podem ser visualizadas e manipuladas através de uma ampla gama de operações e ferramentas, como operações matemáticas, operações entre parâmetros, conversões anemométricas, de unidades e de coordenadas, filtragem, eliminação de ruído, integrações, diferenciações, estatística, ajustes de curva, criação de parâmetros, entre outras. É possível selecionar pontos e intervalos específicos para a realização das operações de forma mais controlada.

 

O programa permite o controle de eventos e pontos de ensaio por tempo de referência, incluindo validação de pontos (de acordo com tolerâncias e faixas de medidas), extração de dados relevantes de cada ponto ou evento (médias, desvios, extremos, etc.), ajuste de curvas (polinomial de graus 0 a 6 e respostas de 1ª e 2ª ordens), e outros dados importantes.

 

O programa também realiza processamento de dados segundo os parâmetros de calibração dos sensores da instrumentação. Os dados de calibração de diferentes aeronaves e calibrações são armazenados em um cadastro e utilizados para o processamento (curvas de correção anemométrica, de sonda de temperatura, ortogonalidade de sensores, calibração de vanes, etc.).

 

O programa suporta uma série de opções de visualização, controle de zoom, edição de formato para cópia e auxílios gráficos como régua, posição do cursor, etiqueta de dados, etc.

 

 

Histórico

 

O R_DAT foi originalmente desenvolvido para MATLAB 4 pelo Cap Eng Rogério Motta Arantes, em função de suas necessidades como Engenheiro-Aluno no Curso de Ensaios em Voo, em 1994. Desde então, o Cap Rogério foi aprimorando e desenvolvendo o programa, até chegar à versão 5.1 em 2002. O programa foi adaptado pelo 1º Ten Eng Artêmio Relvas de Almeida para operação em MATLAB 6.5, recebeu alguns aprimoramentos pelo 1º Ten Eng Leonardo Maurício de Faria Lopes e a revisão do Cap Rogério, até chegar à versão 6.2.

 

Entre 2006 e 2008, o programa foi totalmente reescrito pelo 1º Ten Eng Leonardo, passando a adotar o ambiente de desenvolvimento gráfico do MATLAB 6.5 (GUIDE – Graphic User Interface Development Environment), visando facilitar a interface com o usuário. Foram incorporadas diversas novas funções e funções desenvolvidas ao longo do tempo por engenheiros de ensaios em voo, de forma a centralizar as operações de manipulação, processamento, redução, análise e controle de dados de ensaios em voo, e a substituir integralmente as versões anteriores.

 

Em 2011 foi feita uma adaptação para a versão 7.8 do MATLAB, mantendo-se a compatibilidade com a versão 6.5.

 

 

Versão

 

A versão atual do R_DAT é a 7.0 BETA, liberada em 25/Abr/2008. Versões "BETA" subsequentes serão lançadas até que o software seja consolidado, perdendo essa designação.

As atualizações até a versão BETA 14 somente podem ser executadas em MATLAB 6.5. A versão 7.15 BETA, de 05/Out/2011, foi adaptada para executar em MATLAB 7.8, mantendo a compatibilidade com o MATLAB 6.5 (não foram realizados testes em outras versões).

 

Nota: A designação “BETA” indica que é uma versão liberada para uso em caráter experimental. Os usuários devem compreender que o programa ainda está em fase de testes, o que inclui eliminação de problemas, avaliação de adequabilidade e levantamento de necessidades. Nessa fase, o contato com o programador responsável é fundamental para o aperfeiçoamento e a consolidação do programa.
