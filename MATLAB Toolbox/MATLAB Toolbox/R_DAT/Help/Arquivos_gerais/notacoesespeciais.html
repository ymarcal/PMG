Notações de Tempo Reconhecidas pelo R_DAT

 

Várias funções e operações do R_DAT são dependentes de informações de tempo, como sincronização de arquivos para fusão e concatenação, controle de eventos e pontos de ensaio, entre outras. Outras funções, como importação de dados no formato de texto, se deparam com notações especiais de tempo, não necessariamente um valor numérico simples.

 

Para facilitar a inserção, visualização e importação de valores de tempo com notações especiais, o R_DAT é capaz de reconhecer essas notações, transformando-a em valores numéricos que podem ser trabalhados internamente e vice-versa. As notações reconhecidas são aquelas que utilizam o caractere “dois-pontos” para separar as componentes “horas”, “minutos”, “segundos” e “milissegundos”.

 

A tabela abaixo apresenta todas as notações de tempo reconhecidas pelo R_DAT, alguns exemplos simples e o valor numérico representado pela notação.

A unidade usada internamente pelo R_DAT para operações referenciadas no tempo e para importação de texto é “segundos”.

Notações de Coordenadas Reconhecidas pelo R_DAT

 

Algumas operações do R_DAT são dependentes de informações de coordenadas geográficas, como as conversões de coordenadas.

 

Para facilitar a inserção e visualização de valores de coordenada com notações especiais, o R_DAT é capaz de reconhecer essas notações, transformando-a em valores numéricos que podem ser trabalhados internamente e vice-versa. As notações reconhecidas são aquelas que utilizam caracteres especiais para indicar a direção cardeal e para separar as componentes “grau”, “minuto” e “segundo”.

 

A tabela abaixo apresenta todas as notações de coordenadas reconhecidas pelo R_DAT, alguns exemplos simples e o valor numérico representado pela notação.

A unidade usada internamente pelo R_DAT para operações com coordenadas geográficas é “graus”.

Obs.:

    Caracter de direção cardeal (D): N/S para latitude (norte ou sul) e E/L/W/O para longitude (leste ou oeste). Pode ser posicionado antes ou após os números.

    O uso dos caracteres especiais (símbolo de graus e aspas) é opcional, podendo ser substituídos por espaço.

Notações de Datas Reconhecidas pelo R_DAT

 

Algumas operações do R_DAT são dependentes de informações de data, como o modelo magnético terreste e as propriedades do arquivo.

 

Para facilitar a inserção de datas, o R_DAT é capaz de reconhecer algumas notações. As notações reconhecidas são aquelas que utilizam uma barra para separar as componentes “dia”, “mês” e “ano”.
