Teclas de Atalho da Barra de Menus

 

Os menus podem ser acessados pelo teclado, fazendo uso da tecla "Alt" mais a tecla correspondente à letra sublinhada no nome de cada menu.

Os atalhos são:

 

Atalho

Alt + a

Arquivo

Alt + e

Editar

Alt + f

Funções

Alt + d

Dados

Alt + m

Ferramentas

Alt + o

Opções

Alt + x

Exibir

Alt + j

Ajuda
