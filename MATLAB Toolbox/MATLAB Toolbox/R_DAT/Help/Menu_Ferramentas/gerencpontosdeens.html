Gerenciamento de Pontos de Ensaio

 

O R_DAT permite ao usuário gerenciar e analisar os pontos de ensaio realizados durante o voo. Os pontos de ensaio são organizados em grupos e definidos por um número, um intervalo de tempo (início e fim) e uma descrição sucinta. Um dos parâmetros da matriz de dados é definido como o tempo de referência para a localização dos pontos de ensaio no tempo.

 

Os pontos de ensaio são apresentados no gráfico principal como setas azuis acompanhadas de um texto contendo o número do ponto e, opcionalmente, a descrição. O início de um ponto é definido por uma seta para a direita e o fim do ponto por uma seta para a esquerda. O texto é vinculado ao início do ponto.

 

O controle da exibição dos pontos de ensaio e do respectivo texto é feito pelas seguintes opções do menu “Exibir”:

 

  • Marcadores de pontos de ensaio
  • Descrição dos pontos de ensaio

 O pacote de ferramentas de gerenciamento e análise de pontos de ensaio permite cadastrar e editar os parâmetros dos pontos, definir pontos a partir do gráfico principal, verificar a validade dos pontos, visualizar ajustes de curva e obter vários dados de interesse dos pontos de ensaio. Essas ferramentas são:

 

  • Editor de pontos de ensaio
  • Definir intervalo como ponto de ensaio
  • Definir seleção como ponto de ensaio
  • Validação dos pontos de ensaio
  • Visualização dos ajustes de curva
  • Obter compilação de dados
  • Obter dados de ajustes de curva
  • Obter tabela de dados
