Ferramentas Externas

 

O R_DAT provê acesso a agumas ferramentas externas, que podem não ter relação com os dados das matrizes de trabalho mas podem ser úteis ao usuário.

 

Para acessar essas ferramentas, clique em “Ferramentas ► Ferramentas externas ... ► [opção desejada]”.

 

As ferramentas disponíveis são:

  
  • Calculadora anemométrica
  • Desempenho em curva
  • Conversor de unidades
  • Exportar para o Google Earth
