Processamento de Dados

 

O R_DAT agrega, em uma única ferramenta, várias operações de processamento de dados de voo, como correção de alinhamento de sensores, calibração de sensores, correções anemométricas, obtenção de parâmetros derivados, entre outras.

 

O R_DAT permite armazenar os parâmetros e curvas de calibração de sensores usados no processamento de dados através de um gerenciador de banco de dados, onde as aeronaves e os parâmetros de calibração são cadastrados.

 

As ferramentas utilizadas no processamento de dados são:

 

  • Editor de dados de calibração
  • Ferramenta de processamento de dados
