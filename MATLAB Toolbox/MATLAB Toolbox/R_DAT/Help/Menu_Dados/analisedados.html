Menu Dados    

 

Análise de Dados

 

Esse menu dá acesso a várias funções de análise de dados, como estatística, histograma, análise espectral, entre outras.

As funções de análise disponíveis são:

 

  • Estatística do intervalo
  • Histograma do intervalo
  • Validade de y como tempo
  • Validade de y como top
  • Espectro de potência
  • Resposta em frequência
  • Acesso ao MATLAB Signal Processing Tool
  • Análise de subcomutação

 

Clique no menu “Dados ► Análise de dados ... ► [opção desejada]”.
