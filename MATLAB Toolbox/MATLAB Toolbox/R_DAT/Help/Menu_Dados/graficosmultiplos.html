Gráficos Múltiplos

 

Esse grupo de funções permite visualizar o plote de vários parâmetros em gráficos diferentes.

Os parâmetros adicionais para plotagem podem ser memorizados pelo R_DAT caso a opção "Lembrar parâmetros de exibição múltipla" esteja selecionada.

 

As opções disponíveis são:

 

  • Até 5 gráficos com mesma abscissa
  • Até 5 gráficos com mesma abscissa e 3 plotes

 

Clique no menu “Dados ► Gráficos múltiplos ... ► [opção desejada]”.

 

 

Até 5 Gráficos com Mesma Abscissa

 

Essa função permite visualizar os plotes de até 5 parâmetros em gráficos diferentes.

 

Clique no menu “Dados ► Gráficos múltiplos ... ► Até 5 com mesma abscissa” ou clique no botão  na Barra de Ferramentas.

 

A Caixa de Diálogo solicitará que o usuário indique os parâmetros para plotagem:

 

 

● No campo “x”, selecione a abscissa, que será comum a todos os parâmetros.

 

● No campo “y”, selecione o parâmetro principal.

 

● Nos campos “y2”, “y3”, “y4” e “y5”, selecione até 4 parâmetros secundários. A janela será subdividida em n gráficos, sendo n o último campo com algum parâmetro selecionado (por exemplo: campos y, y2 e y3 selecionados: 3 gráficos; campos y e y4 selecionados: 4 gráficos). Um campo intermediário selecionado em “Nenhum” resultará em um gráfico em branco.

 

Os estilos dos plotes (cores, linhas e marcadores) podem ser alterados pela função “Editar tipos de linhas”.

 

É possível apresentar uma linha vertical para facilitar o sincronismo visual dos gráficos, marcando a opção “Exibir linha de sincronismo”.

 

 

Enquanto a função estiver ativada, não será possível realizar as operações do R_DAT. Clique no botão “Cancela” para desativar a função.

 

 

Até 5 Gráficos com Mesma Abscissa e 3 Plotes

 

Essa função permite visualizar até 5 gráficos com até 3 plotes em cada um.

 

Clique no menu “Dados ► Gráficos múltiplos ... ► Até 5 com mesma abscissa e 3 plotes”.

 

Será apresentada uma janela auxiliar com 5 grupos de campos para que o usuário indique os parâmetros desejados:

 

 

● No campo “x”, selecione a abscissa, que será comum a todos os parâmetros.

 

● Nos demais campos, selecione até 3 parâmetros por grupo. A janela será subdividida em n gráficos, sendo n o último grupo de campos com algum parâmetro selecionado (no exemplo acima: 3 gráficos). Um grupo de campos intermediário sem parâmetros selecionados resultará em um gráfico em branco.

 

Os estilos dos plotes (cor e tipo de linha) são apresentados à esquerda de cada campo e não podem ser alterados.

A ordem dos gráficos segue a numeração à direita dos grupos de campos.

 

É possível apresentar uma linha vertical para facilitar o sincronismo visual dos plotes, marcando a opção “Exibir linha de sincronismo”.

 

 

Enquanto a função estiver ativada, não será possível realizar as operações do R_DAT. Feche a janela auxiliar para desativar a função.
