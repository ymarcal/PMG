Menu Opções    

 

Arrastar

 Essa opção permite ao usuário arrastar o conteúdo do gráfico com o mouse.

 Para habilitar a opção, clique no menu “Opções ► Arrastar”, ou no botão  na Barra de Ferramentas. Enquanto a função estiver habilitada, o menu permanecerá marcado e o botão pressionado.

Essa função inibe a operação do mouse para alteração do zoom, para o qual é possível usar os botões de controle  no canto inferior direito do gráfico.

Para desabilitar a opção de arrastar com o mouse, clique novamente no menu ou no botão , ou dê um clique com o botão direito do mouse. A operação do mouse voltará a ser a alteração do zoom, no modo que estava selecionado anteriormente (normal ou retangular).

 
Operação

 Para arrastar um gráfico, clique e segure o botão esquerdo do mouse e arraste o cursor na direção desejada. Quando houver mais de um gráfico apresentado, a operação pode ser feita sobre qualquer um deles.

Os tipos de cursores apresentados durante a operação da função de arrastar são os seguintes:

Botão do mouse Cursor
Solto
(apenas modo selecionado)
Pressionado
(durante o arrastamento)

A função de arrastar com o mouse apresenta algumas diferenças dependendo do modo de zoom selecionado anteriormente:

Modo do Zoom Descrição
Normal Só é possível arrastar o gráfico na direção do eixo x. O eixo y será ajustado automaticamente.
Retangular É possível arrastar o gráfico em ambas as direções, tanto no eixo x como no y. Nesse caso, a relação de aspecto do gráfico será mantida.
 
 
Nota: O arrastamento é limitado aos extremos dos plotes contidos no gráfico. Não é possível arrastar o gráfico para uma região vazia.
