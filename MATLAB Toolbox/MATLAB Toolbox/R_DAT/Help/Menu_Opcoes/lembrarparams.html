Menu Opções    

 

Lembrar Parâmetros de Exibição Múltipla

 

Essa opção permite ao R_DAT memorizar os parâmetros adicionais selecionados pelo usuário para plotagem múltipla.

 

As funções que fazem uso dessa opção são:

 

  • Até 5 plotes com mesma abscissa
  • Até 16 plotes com mesma abscissa
  • Até 3 plotes com abscissas diferentes
  • Até 5 gráficos com mesma abscissa
  • Até 5 gráficos com mesma abscissa e 3 plotes

 

Por default, o R_DAT sempre inicia com essa opção desselecionada.

  

 

Limpar Parâmetros de Exibição Múltipla

 

Essa opção permite limpar as listas de parâmetros memorizados pelo R_DAT para plotagem múltipla.

Para limpar as listas, clique nessa opção e confirme.
